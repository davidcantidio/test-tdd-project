## Generation Instructions

Based on the product vision above, generate between 3 and 8 epic suggestions that:

1. **Align with the product vision** - Each epic should directly contribute to solving the stated problem
2. **Consider the target user** - Epics should be relevant to the specified user persona
3. **Respect constraints** - All suggestions must work within the listed constraints
4. **Follow logical progression** - Epics should build upon each other when dependencies exist
5. **Be actionable** - Each epic should represent a concrete deliverable

## Epic Format

For each epic suggestion, provide:

- **Title**: A clear, concise name for the epic (max 100 characters)
- **Rationale**: Why this epic is important for the product (2-3 sentences)
- **Tags**: Relevant categories or themes (e.g., "infrastructure", "user-experience", "security")
- **Confidence Score**: A value between 0.0 and 1.0 indicating the AI's confidence in this suggestion
- **Dependencies**: List any epics that must be completed before this one (if applicable)

## Quality Criteria

- **Completeness**: Cover all major aspects of the product vision
- **Feasibility**: Suggest epics that are realistically achievable
- **Value-driven**: Prioritize high-value features that solve core problems
- **Technical soundness**: Ensure technical dependencies are properly ordered
- **User-centric**: Keep the target user's needs at the center of all suggestions
